1. League Scoring Trend

This chart shows how the average first innings score has changed across IPL seasons. It supports the main story by showing whether the league has become more scoring-focused over time.

2. Team Scoring Trends

This chart allows viewers to compare team scoring patterns over time. Use the legend to isolate a specific team or remove teams from view. This makes the interactive element purposeful because the reader can explore which teams contributed most to high-scoring IPL seasons.

3. Team Win Rate Explorer

This chart compares long-term franchise success using win rate. Hover over each bar to inspect exact matches played, wins, and win percentage.

4. Interactive Team-Season Scoring Heatmap

The heatmap shows team scoring patterns across seasons. Darker colours indicate higher average first innings scores. This is useful because it shows that aggressive scoring was not distributed evenly across all teams and seasons.

5. Searchable Team Summary Table

This table gives exact values behind the team win-rate chart. It allows the audience to search, sort, and compare franchises directly.

How this interactive element supports the story

The main report argues that IPL cricket has become more aggressive and higher-scoring over time. This interactive explorer extends that story by allowing the audience to inspect league-level scoring trends, compare franchise success, and explore team-by-season scoring patterns in more detail.
